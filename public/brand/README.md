# AI Vision Forum logos

Original transparent PNGs, preserved at full resolution.

| Asset | Size | Use |
| --- | --- | --- |
| `aivf-logo-transparent.png` | 1680 × 480 | Horizontal logo with white title for dark backgrounds |
| `aivf-logo-black-text-transparent.png` | 1680 × 480 | Horizontal logo with black text for light backgrounds |
| `aivf-avatar-transparent.png` | 1024 × 1024 | Blue square mark for avatars, icons, and either background |
| `aivf-avatar-black-text-transparent.png` | 1024 × 1024 | Square mark with black letters for light backgrounds |

The website uses the blue square mark in navigation and browser icons, and the white-title horizontal logo in the dark footer. Keep the black-text variants for light surfaces; choose by the background behind the logo. The GitHub organization profile switches horizontal variants using `<picture>` and `prefers-color-scheme`.
